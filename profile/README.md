# VinuRepublic | VIR
A Community-driven utility token project on VinuChain dedicated to growing the VINU Ecosystem. We simplify how the community can earn, lock, and burn VINU and VC while providing utmost support to every project building on VinuChain. One can Delegate their VC on the VinuRepublic Node (ID-27) to help in our endeavors!
